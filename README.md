# konsep stack
```C
+-------------------------------------+-------------------+  
|  Argumen ke-2                       |  EBP + 0x0C  (+12)|  
+-------------------------------------+-------------------+  
|  Argumen ke-1                       |  EBP + 0x08  (+8) |  
+-------------------------------------+-------------------+  
|  Saved Return Address               |  EBP + 0x04  (+4) |  
+-------------------------------------+-------------------+  
|  Saved EBP (Old EBP)   <--- EBP     |  EBP + 0x00  ( 0) |  
+-------------------------------------+-------------------+  
|  Local Variable 1                   |  EBP - 0x04  (-4) |  
+-------------------------------------+-------------------+  
|  Local Variable 2                   |  EBP - 0x08  (-8) |

|  ... dst ...                        |  EBP - ...        |  
+-------------------------------------+-------------------+  

```

# stack : dengan canary
```C
HIGH MEMORY
+--------------------------+-------------------+
|  int b                   |  EBP + 0x0C (+12) |
+--------------------------+-------------------+
|  int a                   |  EBP + 0x08 (+8)  |
+--------------------------+-------------------+
|  Return Address          |  EBP + 0x04 (+4)  |
+--------------------------+-------------------+
|  Saved EBP     <-- EBP   |  EBP + 0x00 ( 0)  |
+--------------------------+-------------------+
|  STACK CANARY (random)   |  EBP - 0x04 (-4)  |  <- value hex random, selalu diakhiri null bytes (00)
+--------------------------+-------------------+
|  char buf[5]             |  EBP - 0x0C (-12) |  <- buffer diletakkan PALING DEKAT canary walau di deklarasikan di urutan terakhir
+--------------------------+-------------------+
|  short e                 |  EBP - 0x0E (-14) |  <- non-buffer digeser ke bawah
+--------------------------+-------------------+
|  int d                   |  EBP - 0x14 (-20) |
+--------------------------+-------------------+
LOW MEMORY (arah ESP)
```
